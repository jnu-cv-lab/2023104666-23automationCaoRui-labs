# 📁 2023104666-23automationCaoRui-lab04

## 项目简介
本项目通过生成棋盘格和密集 Chirp 测试图像，系统地研究了图像下采样过程中混叠现象的产生机理，验证了高斯低通滤波器作为抗混叠预滤波的有效性，并实现了基于局部梯度估计的自适应下采样算法。实验涵盖空间域和频域分析，量化了不同高斯核参数对混叠抑制的影响，并比较了自适应与统一下采样的性能差异。

---

## 一、实验原理
### 1. 混叠现象的产生
根据奈奎斯特采样定理，下采样时若信号最高频率超过采样频率的一半（`f_s/2`），会发生频谱混叠，导致图像出现伪影（如棋盘格的摩尔纹、Chirp图的频率反转）。

### 2. 抗混叠预滤波
在**下采样前**使用高斯低通滤波器，将信号带宽限制在 `f_s/2` 以内，可有效消除混叠。理论最优高斯核参数为：
$$ \sigma \approx 0.45M $$
其中 `M` 为下采样倍率（本实验 `M=4`，理论最优 `σ=1.8`）。

### 3. 自适应下采样
基于局部梯度幅值估计图像细节量：
- 细节丰富区域（梯度大）：采用小 `M`（少下采样）、小 `σ`（少模糊），保留细节
- 平滑区域（梯度小）：采用大 `M`（多下采样）、大 `σ`（多模糊），提高压缩效率

## 三、实验步骤与结果
### 第一部分：混叠现象与抗混叠验证
#### 实验步骤
1.  生成 512×512 棋盘格和 Chirp 测试图
2.  直接下采样（`M=4`），观察混叠伪影
3.  加高斯滤波（`σ=1.8`）后下采样，对比差异
4.  计算 FFT 频谱，在频域验证混叠消失

#### 实验结果
- 棋盘格原图：`results/checker_original.png`
- 棋盘格直接下采样（混叠）：`results/checker_direct_downsample.png`
- 棋盘格滤波后下采样（无混叠）：`results/checker_blur_downsample.png`
- Chirp 原图：`results/chirp_original.png`
- Chirp 直接下采样（混叠）：`results/chirp_direct_downsample.png`
- Chirp 滤波后下采样（无混叠）：`results/chirp_blur_downsample.png`

**结果分析**：
- 直接下采样后，棋盘格出现明显摩尔纹，Chirp图出现频率反转，频谱中出现额外的高频分量（混叠）
- 高斯滤波后下采样，空间域伪影完全消失，频谱中高频分量被有效抑制，混叠现象消除

---

### 第二部分：σ公式验证
#### 实验步骤
1.  固定下采样倍率 `M=4`
2.  分别使用 `σ=0.5, 1.0, 2.0, 4.0` 进行滤波下采样
3.  观察 `σ` 过小（混叠残留）和 `σ` 过大（过度模糊）的效果
4.  与理论最优值 `σ≈0.45M=1.8` 对比

**结果分析**：
| σ值 | 效果 | 问题 |
|-----|------|------|
| 0.5 | 滤波不足 | 混叠残留严重，Chirp图伪影明显 |
| 1.0 | 滤波不足 | 混叠部分残留，细节保留较好 |
| 2.0 | 滤波过度 | 图像过度模糊，细节丢失 |
| 4.0 | 严重过度 | 图像完全模糊，细节尽失 |
| 1.8（理论值） | 最优 | 混叠完全消除，细节保留完整 |

实验验证了 `σ≈0.45M` 公式的正确性，该参数可在混叠抑制和细节保留之间取得最佳平衡。

---

### 第三部分：自适应下采样
#### 实验步骤
1.  合成测试图（左棋盘格：细节丰富；右Chirp：平滑渐变）
2.  用 Sobel 算子计算局部梯度幅值，估计细节量
3.  对不同区域采用不同 `M` 和 `σ` 进行自适应下采样
4.  与全图统一下采样对比误差图

#### 实验结果
- 测试图：`results/adaptive_test_img.png`
- 全图统一下采样：`results/uniform_downsample.png`
- 自适应下采样：`results/adaptive_downsample.png`

**结果分析**：
- 统一下采样：对细节丰富的棋盘格区域过度模糊，丢失细节；对平滑的Chirp区域下采样不足，压缩效率低
- 自适应下采样：对棋盘格区域采用小 `M=2` 保留细节，对Chirp区域采用大 `M=4` 提高压缩率
- 自适应下采样总误差显著低于统一下采样，在保证压缩率的同时，大幅提升了图像质量

---

## 四、实验结论
1.  图像下采样必须配合抗混叠预滤波，否则会产生严重的混叠伪影
2.  高斯核参数 `σ≈0.45M` 是下采样前抗混叠滤波的最优理论值
3.  基于局部梯度的自适应下采样算法，可根据图像内容动态调整下采样倍率和滤波强度，在压缩效率和图像质量之间取得更优的平衡
