# Lab04 图像下采样与抗混叠实验

## 项目简介
本项目通过生成棋盘格和密集 Chirp 测试图像，系统地研究了图像下采样过程中混叠现象的产生机理，验证了高斯低通滤波器作为抗混叠预滤波的有效性，并实现了基于局部梯度估计的自适应下采样算法。实验涵盖空间域与频域分析，量化了不同高斯核参数对混叠抑制的影响，并比较了自适应与统一下采样的性能差异。

---

## 实验内容
1. 下采样混叠现象验证
2. 高斯滤波抗混叠效果验证
3. 最优 σ 参数验证
4. 自适应下采样实现与对比实验

## 实验结论
1. 图像下采样必须进行抗混叠预滤波，否则会产生严重伪影。
2. 高斯核参数 σ ≈ 0.45M 可在抗混叠与细节保留之间达到最优平衡。
3. 基于梯度的自适应下采样能根据图像内容动态调整滤波与下采样强度，效果优于统一下采样。
