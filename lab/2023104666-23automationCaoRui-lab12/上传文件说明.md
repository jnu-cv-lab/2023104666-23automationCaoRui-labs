# Lab12 文件上传情况说明

由于本实验采集的棋盘格原始图片均为手机高分辨率照片，单张图片文件较大，全部标定图片（20张）以及生成的结果图片总大小超过了 GitHub 网页上传限制。为保证仓库能够正常提交和下载，同时满足实验报告的展示要求，本次仅上传实验所需的代表性文件。

当前仓库包含以下内容：

```
lab12/
├── lab12.py
├── 实验报告lab12.pdf
├── calibration_images/
│   ├── img01.jpg
│   ├── img05.jpg
│   ├── img10.jpg
│   └── img15.jpg
└── results/
    ├── corners_01.jpg
    ├── corners_02.jpg
    ├── original.jpg
    ├── undistorted.jpg
    └── calibration_result.txt
```

其中：

1. `lab12.py`：完整实验源代码，可直接运行并复现实验结果；
2. `report.pdf`：完整实验报告；
3. `calibration_images`：保留了4张具有代表性的不同姿态棋盘格原始照片，用于展示标定图片采集情况；
4. `results`：包含角点检测结果、去畸变结果以及标定参数文件。

完整的20张标定图片和全部中间结果文件已在本地保存，如有需要，可随时提供完整数据集。
