图像缩小、恢复与频域分析实验报告

一、实验目的

1.掌握图像下采样、插值恢复的基本原理与基于OpenCV的实现方法。
2.对比双线性、双三次两种插值方法对图像恢复效果的影响，理解不同插值算法的优劣。
3.学会使用MSE（均方误差）、PSNR（峰值信噪比）对图像恢复质量进行客观评价。
4.利用二维傅里叶变换（FFT）与离散余弦变换（DCT）对图像进行频域分析，理解空间域与频域的关联。
5.分析下采样与插值恢复操作对图像高频成分、能量分布的影响，掌握频域分析的基本思路。

二、实验原理

1. 图像下采样
   
下采样是降低图像分辨率的操作，为避免直接下采样产生的混叠失真（锯齿、摩尔纹），实验中先对原图进行高斯平滑（低通滤波），去除高频噪声与细节后，再将图像缩小至原尺寸的1/2和1/4。

3. 图像插值恢复

将缩小后的图像放大至原始尺寸，通过插值算法估计新增像素的数值，实验采用两种常用插值方法：
   
   双线性内插：利用待插值像素周围2×2邻域的4个像素值进行线性加权平均，计算速度适中，图像平滑性较好，无明显块效应。
   
   双三次内插：利用待插值像素周围4×4邻域的16个像素值进行三次多项式拟合，细节保留能力更强，图像更平滑，恢复质量优于双线性内插，但计算量更大。

4. 图像质量评价指标

MSE（均方误差）：衡量原图与恢复图的像素值差异，公式为 $$MSE = \frac{1}{H \times W} \sum_{i=0}^{H-1} \sum_{j=0}^{W-1} (I(i,j) - K(i,j))^2$$，值越小，图像失真越小。

PSNR（峰值信噪比）：基于MSE的客观评价指标，公式为 $$PSNR = 10 \log_{10} \left( \frac{255^2}{MSE} \right)$$（8位灰度图），值越大，图像质量越好。

5. 二维傅里叶变换（FFT）

将图像从空间域转换为频域，低频分量对应图像的整体轮廓、亮度信息，高频分量对应图像的边缘、细节与噪声。通过fftshift将频谱中心移至图像中心，对幅度谱取对数显示，便于观察高频与低频的分布差异。下采样与插值恢复会削弱高频分量，导致频谱边缘亮度降低。

6. 离散余弦变换（DCT）

实数域的正交变换，图像能量高度集中在左上角的低频区域（对应图像核心信息），高频区域能量占比极低，是图像压缩的核心原理。实验通过统计左上角25%低频区域的能量占总能量的比例，分析不同恢复方法对图像能量分布的影响。

四、实验代码

import os
import cv2
import numpy as np
import matplotlib.pyplot as plt

def ensure_dir(p):
    if not os.path.exists(p): os.makedirs(p)

def mse(a,b): return np.mean((a-b)**2)

def psnr(a,b):
    m=mse(a,b)
    return 100 if m==0 else 10*np.log10((255**2)/m)

def fft_spectrum(img):
    f=np.fft.fft2(img)
    f=np.fft.fftshift(f)
    return np.log(1+np.abs(f))

def dct2(img): return cv2.dct(np.float32(img))

def energy_ratio(d, r=0.25):
    h,w=d.shape
    hl,wl=int(h*r),int(w*r)
    return np.sum(d[:hl,:wl]**2)/np.sum(d**2)

def save(p, img): plt.imsave(p, img, cmap='gray')

def main():
    base=os.path.dirname(__file__)
    out=os.path.join(base,'results')
    ensure_dir(out)

    img=cv2.imread(os.path.join(base,'input.jpg'),0)
    if img is None:
        print('请放 input.jpg'); return

    # 1️ 原图（1张）
    save(os.path.join(out,'1_original.png'), img)

    # 2️ 下采样（2张：1/2, 1/4）
    blur=cv2.GaussianBlur(img,(5,5),1)
    down_2=cv2.resize(blur,None,fx=0.5,fy=0.5,interpolation=cv2.INTER_NEAREST)
    down_4=cv2.resize(blur,None,fx=0.25,fy=0.25,interpolation=cv2.INTER_NEAREST)
    save(os.path.join(out,'2_down_1_2.png'), down_2)
    save(os.path.join(out,'3_down_1_4.png'), down_4)

    # 3️ 恢复（4张：两种方法 × 两个尺度）
    def restore(down, name_prefix):
        r_lin=cv2.resize(down,(img.shape[1],img.shape[0]),interpolation=cv2.INTER_LINEAR)
        r_cub=cv2.resize(down,(img.shape[1],img.shape[0]),interpolation=cv2.INTER_CUBIC)
        save(os.path.join(out,f'{name_prefix}_bilinear.png'), r_lin)
        save(os.path.join(out,f'{name_prefix}_bicubic.png'), r_cub)
        return r_lin, r_cub

    r2_lin, r2_cub = restore(down_2, '4_restore_1_2')
    r4_lin, r4_cub = restore(down_4, '5_restore_1_4')

    # 4️ 空间域指标（打印）
    print('--- Spatial Metrics ---')
    for name, r in [('1/2-bilinear',r2_lin),('1/2-bicubic',r2_cub),
                    ('1/4-bilinear',r4_lin),('1/4-bicubic',r4_cub)]:
        print(name, 'MSE=%.2f PSNR=%.2f'%(mse(img,r), psnr(img,r)))

    # 5️ FFT（3张：原图、1/2下采样、1/2双线性恢复）
    save(os.path.join(out,'6_fft_original.png'), fft_spectrum(img))
    save(os.path.join(out,'7_fft_down_1_2.png'), fft_spectrum(down_2))
    save(os.path.join(out,'8_fft_restore_bilinear.png'), fft_spectrum(r2_lin))

    # 6️ DCT（3张：原图、双线性、双三次）
    d_o=dct2(img)
    d_lin=dct2(r2_lin)
    d_cub=dct2(r2_cub)

    save(os.path.join(out,'9_dct_original.png'), np.log(1+np.abs(d_o)))
    save(os.path.join(out,'10_dct_bilinear.png'), np.log(1+np.abs(d_lin)))
    save(os.path.join(out,'11_dct_bicubic.png'), np.log(1+np.abs(d_cub)))

    print('\n--- DCT Energy Ratio ---')
    print('original:', energy_ratio(d_o))
    print('bilinear:', energy_ratio(d_lin))
    print('bicubic:', energy_ratio(d_cub))

    # 7️ 一张总对比图（第12张）
    fig,ax=plt.subplots(2,3,figsize=(10,6))
    ax[0,0].imshow(img,cmap='gray'); ax[0,0].set_title('Original')
    ax[0,1].imshow(down_2,cmap='gray'); ax[0,1].set_title('Down 1/2')
    ax[0,2].imshow(r2_lin,cmap='gray'); ax[0,2].set_title('Bilinear')
    ax[1,0].imshow(down_4,cmap='gray'); ax[1,0].set_title('Down 1/4')
    ax[1,1].imshow(r4_lin,cmap='gray'); ax[1,1].set_title('Bilinear 1/4')
    ax[1,2].imshow(r2_cub,cmap='gray'); ax[1,2].set_title('Bicubic')
    for a in ax.ravel(): a.axis('off')
    plt.tight_layout()
    plt.savefig(os.path.join(out,'12_summary.png'))
    plt.close()

    print('\n 已生成12张图片（results文件夹）')
    if __name__=='__main__':
    main()

五、实验步骤
1. 图像读入与预处理：读取灰度图像input.jpg，保存原图至results文件夹。
2. 下采样操作：对原图进行高斯平滑后，分别缩小至1/2、1/4尺寸，保存缩小图。
3. 图像恢复：使用双线性、双三次插值方法，将缩小后的图像恢复至原始尺寸，保存恢复图。
4. 空间域质量评价：计算各恢复图与原图的MSE、PSNR，打印结果并分析。
5. 傅里叶变换分析：对原图、1/2下采样图、双线性恢复图进行FFT，生成并保存频谱图，分析高频成分差异。
6. DCT变换分析：对原图、双线性恢复图、双三次恢复图进行DCT，生成并保存系数图，计算低频能量占比并分析。
7.生成包含所有关键图像的汇总对比图，便于直观观察实验结果。

2. 空间域质量指标（MSE、PSNR）

实验运行实际结果：

--- Spatial Metrics ---
1/2-bilinear MSE=11.67 PSNR=37.46
1/2-bicubic MSE=10.72 PSNR=37.83
1/4-bilinear MSE=17.19 PSNR=35.78
1/4-bicubic MSE=17.08 PSNR=35.81

结果分析：

下采样比例影响：同一插值方法下，1/2下采样的恢复效果明显优于1/4下采样，原因是1/4下采样丢失的图像信息更多，恢复时无法完全弥补，导致失真更严重。

插值方法影响：同一下采样比例下，双三次插值的MSE更小、PSNR更高，说明双三次插值的恢复质量优于双线性插值，能更好地保留图像细节。

整体趋势：下采样倍数越大，MSE越大、PSNR越小，图像恢复质量越差；双三次插值始终优于双线性插值。

3. 傅里叶变换频谱分析

频谱差异分析：

原图频谱：中心低频区域亮度高，边缘高频区域有明显细节，说明原图包含丰富的高频信息（边缘、纹理等），图像细节完整。

1/2下采样频谱：高频区域亮度大幅降低，仅保留少量高频信息，原因是下采样过程会滤除高于奈奎斯特频率的高频分量，导致细节丢失，避免混叠失真。

双线性恢复频谱：高频区域亮度进一步降低，说明插值恢复过程是一种平滑操作，会进一步抑制高频分量，使图像更柔和，但也会损失部分细节。

结果分析：

原图能量分布：原图的低频能量占比已达99.65%，说明DCT变换的能量压缩特性显著，图像的核心信息（轮廓、亮度）主要集中在低频区域。

恢复图能量分布：双线性、双三次恢复图的低频能量占比均高于原图（接近99.9%），说明插值恢复过程会平滑图像，抑制高频分量，使能量更集中在低频区域。

两种插值方法对比：双线性恢复图的能量占比（99.96%）略高于双三次恢复图（99.93%），说明双线性插值的平滑效果更强，对高频分量的抑制更彻底；双三次插值保留了少量高频细节，因此能量占比略低。

七、实验结论
1. 下采样倍数与恢复质量呈负相关：下采样倍数越大，图像细节丢失越多，恢复后的失真越明显，MSE越大、PSNR越小。
2. 插值方法的优劣：双三次插值的恢复质量优于双线性插值，能更好地保留图像细节，对应的MSE更小、PSNR更高。
3. 频域特性变化：下采样会滤除图像的高频分量，插值恢复会进一步平滑图像、抑制高频，导致FFT频谱的高频区域亮度降低。
4. DCT能量分布：图像DCT能量高度集中在低频区域，插值恢复会使能量更加集中，平滑效果越强，低频能量占比越高。
5. 高斯预滤波的作用：下采样前进行高斯平滑，可有效减少混叠失真，使缩小图和恢复图的视觉效果更平滑，无明显锯齿。
